# Skills for Software Engineers

[![skills.sh](https://skills.sh/b/Carbocode/agent-skills)](https://skills.sh/Carbocode/agent-skills)

These are the skills I use in my day-to-day work to design software and document it with rigor, clarity, and craft.

## Available Skills

| Skill          | Description                                                                                                                                                                                                                                                               | Location                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `uml-modeling` | Design, review, and refine UML diagrams from a modeling and communication perspective. It helps an AI assistant choose the right UML diagram type, reason about abstraction level and boundaries, and repair diagrams that are syntactically valid but semantically weak. | [`skills/uml-modeling`](skills/uml-modeling) |

## Installation

### Claude Code

```text
/plugin marketplace add Carbocode/skills
/plugin install uml-modeling@carbocode-skills
```

### Cursor

```text
/add-plugin uml-modeling
```
